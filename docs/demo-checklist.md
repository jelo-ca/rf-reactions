# Demo checklist

- [ ] Same laptop, camera and lighting as calibration. Plain background behind the card.
- [ ] Open the app once beforehand. The first load compiles the WebGPU shaders, and later loads are
      much faster (measured cold start: 16.3 s first load, 8.1 s after).
- [ ] Run the parity page once (`#parity` → PASS).
- [ ] Check the debug panel: backend `webgpu`, detector loaded, fps steady.
- [ ] Have at least one tier 3–4 card ready (a printed proxy is fine for a private demo). Test the
      sound level with T.
- [ ] Record a backup video of a clean run.
- [ ] Keep the debug panel ready for engineers (D): live scores, timings, backend. Export the session
      afterwards.
